# 鉄道路線プランナー（デモ版 / Phase 1）

自分で駅を好きな順番に並べて、区間ごとの列車候補を選びながら一日の鉄道旅程を組み立てるWebアプリ。
`rail-route-builder_design.md`（親フォルダ）のPhase 1にあたるデモ版で、**APIキー不要・完全無料**で動く。

> 🧪 表示される時刻・運賃はすべてMockProvider（架空データ）。実際の時刻表ではない。

## 起動方法

`起動.bat` をダブルクリックする（初回だけ `npm install` が自動で走る）。
ブラウザが自動で開く（`http://localhost:5173`）。

コマンドで起動する場合:

```bash
npm install
npm run dev
```

## 使い方

1. 旅行日と出発時刻を設定する
2. **地図上の駅をタップ→「＋この駅を追加」**、または駅名検索で2〜10件追加する（ひらがなでも検索できる）
3. ドラッグまたは▲▼で駅順を変更、途中駅の「この駅で必要な時間」を設定する
4. 「時刻を検索」を押すと全区間の時刻がつながって表示される
5. 各区間の「他の候補を見る」から便を変更できる。変更した便は🔒固定され、後続区間だけ再計算される
6. 「保存」でプランを端末内（localStorage）に保存できる

選んだ駅は地図上に番号ピン＋ピンクの破線で表示される。

## 画面の見かた

地図が画面いっぱいの主役で、左右のパネルが上に浮いている。パネル見出し（🧭プランを組む／🚃旅程と時刻）を押すと畳めるので、地図を広く見たいときは畳む。スマートフォンでは地図が上、下がタブ切り替えになる。

### 線路の色分け（凡例は地図下部中央）

| 色 | 種別 |
| --- | --- |
| 濃い青（太） | 新幹線 |
| 緑 | JR在来線 |
| オレンジ | 私鉄（民営鉄道） |
| 紫 | 地下鉄・公営 |
| 青灰 | 第三セクター |
| 青緑 | モノレール・新交通 |
| 茶 | 路面電車・ケーブル |
| ピンクの破線 | あなたが組んだ旅程 |

- **凡例の色をクリックすると、その種別だけ消したり出したりできる**（「すべて表示」「すべて隠す」「新幹線とJRだけ」のショートカットつき）
- ズーム8未満では新幹線とJRだけを描く（縮小時に全部描くと地図が線で埋まって読めなくなるため）
- ズーム9以上では**線路にカーソルを合わせると路線名と運営会社**が出る

### 旅程の線は線路をなぞる

駅どうしを直線で結ぶのではなく、**実際の線路をたどって**描く。白い縁取りつきのピンクの線がそれ。
仕組みは、線路データから作った経路探索用ネットワーク（`src/data/rail-graph.json`）の上でダイクストラ法を走らせ、通った線形をつないでいる。線路をたどれない組み合わせ（離島など）のときだけ、破線の直線に落ちる。

## データについて（すべて無料・出典表示が条件）

| データ | 出典 | ライセンス |
| --- | --- | --- |
| 地図タイル | OpenStreetMap | © OpenStreetMap contributors（ODbL） |
| 駅の位置（約8,700駅） | OpenStreetMap | © OpenStreetMap contributors（ODbL） |
| 線路（8,062本） | 国土数値情報 鉄道データ N02（国土交通省） | 国土数値情報利用約款 |

**地図右下のクレジット表記と、画面下の帯の出典表記を消さないこと**（表示が利用条件）。

### データの更新方法

```bash
node scripts/fetch-stations.mjs    # 駅        → src/data/stations-jp.json
node scripts/build-railways.mjs    # 線路(描画) → src/data/railways-jp.json
node scripts/build-rail-graph.mjs  # 線路(経路) → src/data/rail-graph.json
```

`build-rail-graph.mjs` は `build-railways.mjs` が落としたZIPを使うので、**この順に実行**すること。

- `build-railways.mjs` は国土交通省のZIP（約12MB）を `.cache/` へ落として変換する。2回目以降はキャッシュを再利用する（最新年度に上げたいときは、スクリプト冒頭の `ZIP_URL` の年度部分を差し替える）
- 描画用データは、細切れの区間を路線ごとにつなぎ、Douglas-Peuckerで約50m精度まで間引いている（13.6MB → 1.1MB）
- 経路用データは、分岐点・末端・駅のそばの点だけを「節」として残し、あいだの連なりを1本の「辺」にまとめている。37.7万点 → 節1万・辺1万・0.7MB。座標は1e-5度きざみの差分整数で持たせて圧縮した
- どちらも重いので**遅延読み込み**している。描画用は地図を出したあと、経路用は駅が2つ以上そろってから読む（別チャンクに分かれる）

### 時刻データについて

主要33駅だけは路線名つきの手入れデータ（`mock-provider.ts`内）。それ以外の駅を含む区間は「在来線ルート」として概算表示する。いずれも**時刻・運賃は架空**。

手入れした33駅の座標はおおよその値なので、起動時に**同名のOSM実データでいちばん近いものへ補正**している（座標がずれていると線路に対応づけられず、旅程の線が線路をなぞらなくなるため）。

## 構成

```text
src/
  components/   画面部品（MapPicker=地図, Timeline=時刻表 など）
  data/         全国の駅・線路データ(JSON)と、線路の色定義(railway-style.ts)
  lib/          時刻連鎖(chain.ts)・集計(totals.ts)・日時(time.ts)
  providers/    TransitProviderインターフェース と MockProvider
  state/        Zustandストア・localStorage保存
scripts/        駅・線路データの取得/変換スクリプト
tests/          Vitest単体テスト
```
